# Roadmap

The initial release focuses on the live terminal and basic mobile controls.
These are planned improvements, not features available in v0.1.0. Version
numbers and dates will be assigned when a change is ready to publish.

- Improve Chinese IME composition and soft-keyboard viewport handling.
- Improve text selection and copying on Android.
- Add native text selection through a transparent DOM mirror.
- Improve touch scrolling while preserving the live TUI and terminal mouse behavior.
- Expand quick keys into an optional PC-style keyboard.
- Improve reconnect handling and document behavior across browsers.

Each release should include its behavior changes, known limitations and verification results.
